# 集中タイマー

勉強時間を記録できるポモドーロタイマー（PWA）。GitHub Pages で公開し、Android のホーム画面にアプリとしてインストールできます。

## 公開手順（GitHub Pages）
1. このフォルダの中身をリポジトリのルートに置いて push
2. リポジトリの Settings → Pages → Build and deployment
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** → Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## Android へのインストール
1. Chrome で公開URLを開く
2. メニュー（︙）→「アプリをインストール」または「ホーム画面に追加」
3. ホーム画面のアイコンから起動すると、アドレスバーのない全画面アプリとして動きます

## データについて
- 記録・タスク・設定は **その端末のブラウザ内（localStorage）** に保存されます。端末間の同期はありません。
- 設定画面の「バックアップ」から JSON で書き出し・取り込みができます（端末の移行やバックアップ用）。
- ブラウザのサイトデータを消去すると記録も消えるため、定期的な書き出しをおすすめします。

## 更新するとき
`sw.js` の `CACHE` の値（例：`focus-timer-v2` → `v3`）を変えてから push すると、インストール済みのアプリにも更新が確実に反映されます。
