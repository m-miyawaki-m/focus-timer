# 集中タイマー 現状の設計書

- 作成日: 2026-10-06。更新: 2026-10-06（ソースを src/ の ES モジュールに分けた）
- 位置づけ: 今の実装をまとめた、ただ 1 つの設計書。食い違うときは本書が正（コードと合わなければ本書を直す）。
- 対象: スマホ（Android の Chrome、ホーム画面に入れて使う）と PC のブラウザ。

## 1. 全体の構成

```
ブラウザ（index.html + style.css + src/ の ES モジュール）
   ├─ localStorage（記録・タスク・設定・タイマーの状態。端末ごと、同期なし）
   └─ Service Worker（sw.js。オフラインで開けるようにキャッシュ）
公開: GitHub Pages（静的ファイルをそのまま配る。ビルドなし）
```

- バックエンド・ビルド・外部ライブラリは無い。外から読むのは Google Fonts（Zen Kaku Gothic New）だけ。
- PWA: `manifest.webmanifest` でホーム画面に入れられる（全画面、テーマ色 `#1E2A5A`）。

### 1.1 ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の構造だけ（タイマー・記録・設定の 3 つのタブ、タスクのドロワー）。`src/main.js` を ES モジュールで読む |
| `style.css` | 見た目。ライト／ダーク（`prefers-color-scheme`）、表示の切り替え（`data-look`・`data-scene`）、集中中の自動非表示（`body.idle`） |
| `src/config.js` | 設定値（`APP_CONFIG`）: 設定の初期値・科目・科目の色・モード名・localStorage のキー |
| `src/main.js` | 起動。状態を読み、画面の部品を `ctx` でつなぎ、0.25 秒ごとに確かめる。タブの切り替え。Service Worker の登録 |
| `src/store.js` | 状態（設定・記録・タスク・タイマー）を持つ唯一の場所。localStorage の読み書き、別タブの変更 |
| `src/core/` | DOM を使わない計算（テストの対象）: `time.js` 日付、`timer.js` タイマーの状態、`stats.js` 集計、`tasks.js` タスク、`settings.js` 設定の欄、`backup.js` CSV・JSON |
| `src/ui/` | 画面: `timer-view.js` タイマー、`tasks-view.js` タスク、`stats-view.js` 記録、`settings-view.js` 設定、`look.js` 見た目・自動非表示、`background.js` 背景・花火、`feedback.js` トースト・音、`dom.js` 小さな道具 |
| `sw.js` | キャッシュ（`CACHE` の名前を変えると古いキャッシュを消す） |
| `manifest.webmanifest`・`icon-*.png` | PWA の設定とアイコン |
| `test/` | vitest（`core/` と `store.js`） |

### 1.2 つなぎ方

- 依存は `ui/` → `store.js` → `core/`・`config.js` の一方向。`core/` は `config.js` と `core/` の中だけを読む。
- `ui/` どうしは直接読まず、`main.js` が作る `ctx`（`toast`・`celebrate`・`applyLook`・`renderNow`・`renderAll` など）を通して呼ぶ。`ui/dom.js` だけはどこから読んでもよい。
- 状態を変えるのは `store.js` の関数だけ（例外: タイマーの `taskId`・`subject` は ui が直に変えて `saveTimer()` を呼ぶ）。記録の追加・削除、取り込み、別タブの変更のときは `notify()` で `renderAll()` を呼ぶ。ほかの変更は呼ぶ側が要る所だけ描き直す。
- `core/` の関数は「今」を引数 `now` で受け取る。

## 2. 画面

画面は 1 ページで、上のボタンでタブを切り替える（URL は変わらない）。

| 画面 | 開き方 | 中身 |
|---|---|---|
| タイマー | 起動時・「集中タイマー」の文字 | 文字盤（押すと開始／一時停止）、モード表示（押すと見た目を切り替え）、「記録して終了」「リセット」 |
| 記録 | 「記録」（もう一度押すとタイマーへ） | 今日・今週（目標のバー）・今月・連続日数、直近 14 日のグラフ、科目別（今週）、手動で追加、履歴（直近 60 件）、CSV で保存 |
| 設定 | 「設定」（もう一度押すとタイマーへ） | タイマー、目標と科目、背景アニメーションと花火、バックアップ |
| タスク（ドロワー） | 上の「#N タスク名」 | タスクの一覧・追加・編集、完了済みを消す、タスク未選択時の科目、今回のメモ |

- 上にはいつも「今日 ○分」「今週 ○分 ／ 目標 ○時間」を出す。
- タスクのドロワーは、幅 900px 以上では横に並べて出す（画面を覆わない）。開いているかは覚えておく（`pomo.drawer.v1`）。
- 操作が無いとき: 画面の下に「ブラウザに保存できませんでした…」（保存に失敗したときだけ）、トーストで結果を 3.2 秒出す。

## 3. タイマー

### 3.1 モードと流れ

| モード | 表示名 | 長さ（初期値） |
|---|---|---|
| `focus` | 集中 | 25 分 |
| `short` | 小休憩 | 5 分 |
| `long` | 長休憩 | 15 分 |

- 集中が終わると、`cycle` を 1 足し、`cycle` が「長休憩までの集中回数」（初期値 4）で割り切れれば長休憩、でなければ小休憩にする。
- 休憩が終わると集中に戻す。
- 「集中が終わったら休憩を自動で始める」が入っていれば、休憩をそのまま始める（休憩の後の集中は自動では始めない）。
- 文字盤の下の点は、今のセットで何回集中を終えたか（`cycle` を回数で割った余り）。

### 3.2 操作

| 操作 | 動き |
|---|---|
| 文字盤を押す／Enter・Space（文字盤にフォーカス）／Space（入力欄・ボタン以外） | 開始 ⇄ 一時停止 |
| 記録して終了（集中） | 一時停止し、それまでの時間を記録して休憩へ。1 分未満なら記録せず集中の最初に戻す。タスクの実績は増やさない |
| 休憩をスキップ（休憩） | 集中の最初に戻す |
| リセット | 今のモードの最初に戻す（記録しない） |

### 3.3 時間の計り方

- 状態 `t` を localStorage（`pomo.timer.v1`）に置き、閉じて開き直しても続く。
  - `endAt`: 終わる時刻、`remainingMs`: 一時停止中の残り、`accMs`: 実際に動いた時間の合計、`startAt`: 最初に始めた時刻、`resumedAt`: 最後に再開した時刻、`cycle`、`subject`（タスク未選択時の科目）、`taskId`（選んでいるタスク）。
- 0.25 秒ごとと、画面が見えるようになったとき（`visibilitychange`）に、終わる時刻を過ぎていないか確かめる。止まっていた間に過ぎていても、開いたときに終わったものとして扱う。
- 記録する分は `accMs` を分に丸めたもの（一時停止していた時間は入れない）。

### 3.4 終わったとき（時間切れ）

- チャイムを鳴らす（一度でもタイマーを開始して音を使えるようになっていれば）。
- 集中なら: 記録し、選んでいるタスクの実績を 1 足し、花火（設定で入っていて、動きを減らす設定でないとき）を上げ、「○分を記録しました。小休憩に入りましょう」。

### 3.5 見た目（モード表示のボタン）

押すたびに シンプル → グラデーション → アニメ と切り替える（`pomo.look.v1` に覚える）。切り替えのときは色を一度かぶせてなじませる。

| 見た目 | 中身 |
|---|---|
| シンプル | 明るい背景、目盛り（60 本）が残りに合わせて消える |
| グラデーション | モードごとのグラデーション背景（集中 `#24357F`・小休憩 `#1F8AA6`・長休憩 `#8A7ADB`）、白い円の進み具合 |
| アニメ | グラデーションの見た目に、canvas の背景（6 章）を重ねる |

### 3.6 集中中の自動非表示

- 集中を動かしていて、タイマーのタブを見ていて、ドロワーが閉じていて、入力欄にフォーカスが無いとき、3 秒操作が無いと上・モード表示・ボタンを消す（5 秒かけて薄くする）。
- マウス・キー・ホイール・タッチで戻す。消えているときのタッチは、戻すだけでタイマーは止めない。

## 4. タスク

- 1 件: `{id, title, subject, est（見積もりポモドーロ数 1〜50）, done（実績 0〜99）, completed}`。100 件まで。
- 1 件を「選んでいる」タスクにでき（行を押す）、集中の記録にそのタスクの科目・名前が付く。完了したタスクは選べない。
- 新しく足したとき、選んでいるタスクが無ければそれを選ぶ。
- 行の表示: 完了のチェック、名前と科目、ブロック（見積もりの数だけ、実績の分を科目の色で塗る。見積もりを超えた分は別の印。20 個まで出して残りは「+N」）、編集。
- 編集: 名前（60 字まで、Enter で保存）、科目、見積もり（−／＋、「約○時間」も出す）、実績（編集のときだけ）、削除。
- 下の欄: すべてのタスクのブロック（40 個まで）と「残り N ポモ（約○分）」（完了していないタスクの見積もり − 実績）。
- 上の「#N」は、集中のときは今日の（手動でない）記録の数 + 1、休憩のときは今日の記録の数。上のバッジは完了していないタスクの数。
- タスクを選んでいないときは、「タスク未選択時の科目」で科目を選ぶ（初期は科目の先頭）。

## 5. 記録

### 5.1 1 件の形

```js
{id, start, end, min, subject, memo, taskId?, task?, manual?}
```

- `start`・`end` はミリ秒の時刻。`min` は分。`task` は記録したときのタスク名（後でタスク名を変えても変わらない）。
- タイマーの記録: メモはドロワーの「今回のメモ」（記録したら空にする）。
- 手動で追加: 日付・開始時刻（空なら 12:00）・時間（1〜600 分）・科目・メモ。`manual: true` を付ける。
- 履歴の「削除」で 1 件ずつ消せる（確かめずに消す）。

### 5.2 集計（記録タブ）

| 項目 | 決まり |
|---|---|
| 今日・今月 | 開始の日付（端末の時刻）で数える |
| 今週 | 月曜 0 時から。目標（時間）に対するバー |
| 連続日数 | 今日（今日の記録が無ければ昨日）からさかのぼって、記録のある日が続く日数 |
| 直近 14 日 | 日ごとに科目で積み上げた棒グラフ。縦軸は 1 時間ごと（最大が大きいときは間引く）。科目の並びは設定の科目の順、設定に無い科目は後ろ |
| 科目別（今週） | 多い順の横棒 |
| 履歴 | 新しい順に 60 件、日ごとにまとめて合計を出す |

### 5.3 科目の色

`src/config.js` の `COLORS`（8 色）を、設定の科目の並び順に割り当てる。設定に無い科目（消した科目の古い記録）は、科目の数の位置の色。

## 6. 背景アニメーション

見た目が「アニメ」のときだけ出す。速さは設定（10〜150%）。動きを減らす設定（`prefers-reduced-motion`）では 3 割の速さにし、切り替えのなじませと花火はやめる。

| 場面 | 使うとき | 中身 |
|---|---|---|
| `snow` マリンスノーとクラゲ | 集中（初期値） | 暗い青、降る粒、右下のクラゲ |
| `glass` 窓の雨 | 集中で選んだとき | ぼけた光、ときどき流れる雨粒 |
| `fire` 夜空の花火 | 休憩（初期値） | 星と、数秒おきの花火 |

- 休憩の背景で「集中中と同じ」を選ぶと、休憩も集中の場面にする。
- 花火（集中が終わったとき）: 大きい花火を 6 回。見た目がアニメでなくても、canvas を上に重ねて出す。

## 7. 設定

| 項目 | 範囲（外れたら初期値） | 初期値 |
|---|---|---|
| 集中（分） | 1〜180 | 25 |
| 小休憩（分） | 1〜60 | 5 |
| 長休憩（分） | 1〜90 | 15 |
| 長休憩までの集中回数 | 2〜10 | 4 |
| 休憩を自動で始める | ― | オフ |
| 週の目標（時間） | 1〜100 | 15 |
| 科目（1 行に 1 つ） | 空行・重複を除いて 12 個まで。空なら初期値 | 応用情報・簿記論・財務諸表論・その他 |
| 集中中の背景 | snow / glass | snow |
| 休憩中の背景 | fire / same | fire |
| 動きの速さ | 10〜150% | 50% |
| 集中が終わったら花火 | ― | オン |

- 初期値は `src/config.js` の `DEFAULTS`。「設定を保存」を押したときだけ保存する。
- 保存した設定があれば、初期値より保存した値を使う（項目ごと。新しく足した項目は初期値になる）。

## 8. 保存とバックアップ

### 8.1 localStorage

| キー | 中身 |
|---|---|
| `pomo.data.v1` | `{settings, months, tasks}`。`months` は `{"YYYY-MM": [記録…]}` |
| `pomo.timer.v1` | タイマーの状態（3.3） |
| `pomo.look.v1` | 見た目（`simple`・`grad`・`anim`） |
| `pomo.drawer.v1` | ドロワーを開いているか |

- 変えるたびに `pomo.data.v1` を丸ごと書き直す。失敗したら画面の下に知らせる。
- 同じ端末の別のタブで変わったら読み直す。
- 端末・ブラウザの間の同期は無い。サイトのデータを消すと記録も消える。

### 8.2 書き出し・取り込み

- CSV（記録タブ）: `study-log-YYYY-MM-DD.csv`。BOM 付き UTF-8、列は 日付・開始・終了・分・科目・タスク・メモ・手動。
- JSON（設定タブ）: `focus-timer-backup-YYYY-MM-DD.json`。`{app:'focus-timer', version:1, exportedAt, settings, months, tasks}`。
- 取り込み（JSON）: `app` が `focus-timer` でなければ断る。
  - 記録: 月ごとに、`id` が無いものだけ足す（重複しない）。
  - タスク: `id` が無いものだけ、100 件までの空きの分だけ足す。
  - 設定: 取り込んだファイルの値で上書きする。

## 9. オフライン（Service Worker）

- 入れたときに、ページ・CSS・`src/` の JS すべて・manifest・アイコンをキャッシュする（`CACHE` = `focus-timer-v3`）。
- ページ（画面を開く要求）: ネットを先に使い、取れたらキャッシュを入れ替える。つながらなければキャッシュ。
- それ以外（同じサイトのファイルと Google Fonts）: キャッシュを先に使い、無ければ取ってキャッシュする。
  - そのため CSS・JS を変えたときは `CACHE` の名前を変えないと、入れてある端末に届かない。
